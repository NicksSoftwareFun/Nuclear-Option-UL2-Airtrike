UL-2 Airtrike 1.0.0, the first full release.

A two-seat armed gyrocopter for Nuclear Option, with a third-seat door gunner kit (Machine Gunner, Grenadier or Spotter), nose laser designator and light rocket and missile loadouts.

**Install:** put `UL2Airtrike.dll` in `BepInEx\plugins`. Requires BepInEx 5 and Blueprinter. If you have a UL-2 TEST BUILD installed, remove it first (both use the same plugin ID).

**New since release candidate 2**
- The seat 3 Machine Gunner, Grenadier and Spotter hands use the same closed glove fist as the pilots, fitted round each grip and binocular side, in the camo colour of their sleeves.
- The main rotor blur sits level with the hub bar.
- Two missions ship with the mod: "UL-2 - Reservist Aerial Gunnery" and "UL-2 - Altercation".
- New skin damage map: light bare metal with no darkening, and the hull shreds into ragged torn shards. A ragged strip of skin stays along every part edge, so no damaged skin is left floating.
